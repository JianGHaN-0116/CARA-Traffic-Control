## Regenerating Figures

The figure generation script (`scripts/generate_paper_figures.py`) is available in the public GitHub repository, not in this supplementary evidence package.

```bash
# Clone the repository and run from the project root:
git clone https://github.com/JianGHaN-0116/CARA-Traffic-Control.git
cd CARA-Traffic-Control
python scripts/generate_paper_figures.py
```
