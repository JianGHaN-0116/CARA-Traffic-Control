# Reproducibility Guide

Pinned commit: `e5a1abd`

## Environment Setup

```bash
conda create -n cara-tc python=3.10 -y
conda activate cara-tc
pip install -r requirements.txt
```

## Quick Reproduction (Pre-computed Data)

No dataset download required. Reproduces all six core evidence tables:

```bash
pip install pandas pyyaml
python scripts/reproduce_review_tables.py
```

Output: `outputs/paper_tables/review_table{6,7,9,12,13,17}.csv` and `.md`

## Full Reproduction from Raw Datasets

### Step 1: Download Datasets

- Edge-IIoTset: https://github.com/ICL-ml4csec/Edge-IIoTset (~2 GB)
- CIC-IDS2017: https://www.unb.ca/cic/datasets/ids-2017.html (~5 GB)

Place in `src/data/raw/`.

### Step 2: Preprocess

```bash
python src/preprocessing/build_streaming_windows.py edge_iiotset
python src/preprocessing/build_streaming_windows.py cic_ids2017
```

### Step 3: Train Detectors

```bash
python src/detectors/evaluate_detector.py --config configs/detector_config.yaml
```

### Step 4: Build Windows and Train Controllers

```bash
# Main split (Table 5)
python src/experiments/fair_comparison.py

# Non-overlap split (Table 8, non-overlap block)
python src/experiments/nonoverlap_window_eval.py

# Chronological split (Table 8, chronological block)
python src/experiments/chronological_split_multiseed.py

# CIC-IDS2017 cross-dataset (Table 9)
python src/experiments/cross_dataset_eval.py
```

### Step 5: Feature Ablation

```bash
python src/experiments/feature_ablation_stress.py
python src/experiments/feature_ablation_full_comparison.py
```

### Step 6: Score Calibration

```bash
python src/experiments/score_calibration_eval.py
```

### Step 7: Robustness Checks

```bash
# Blocked chronological CV
python src/experiments/blocked_chrono_cv.py

# Endpoint-disjoint split
python src/experiments/endpoint_disjoint_eval.py

# Attack-family holdout
python src/experiments/attack_family_holdout.py
```

### Step 8: OVS/Mininet Replay (requires root + OVS)

```bash
cd ovs_replay
bash scripts/run_enhanced_replay.sh
bash scripts/collect_metrics.sh
```

## Expected Runtime

| Component | Time (single seed) |
|---|---|
| Detector training (XGBoost) | ~2 min |
| DQN-TFC training | ~5 min |
| PPO-TFC training | ~8 min |
| Feature ablation (4 variants) | ~10 min |
| Score calibration | ~5 min |
| OVS replay (500 steps) | ~15 min |
| Full reproduction (all tables) | ~60 min |

## Seeds

All learned controllers use three seeds: {42, 123, 456}. Results are reported as mean +/- std.

## Configuration Files

- `configs/dataset_config.yaml`: window size, stride, attack threshold per dataset
- `configs/detector_config.yaml`: XGBoost hyperparameters (trees, depth, learning rate)
- `configs/drl_config.yaml`: DQN/PPO hyperparameters (learning rate, batch size, buffer size)
- `configs/experiment_config.yaml`: validation grid, seeds, training budgets
- `supplement/configs/selected_controllers.yaml`: final selected hyperparameters for each controller
